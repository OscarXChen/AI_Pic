# 有些风险，不会弹窗

**别让熟悉的环境，成为放松警惕的理由。**

面向高校、科研机构与研发团队的计算机实验室安全教育系列。电脑、服务器和插排看起来再熟悉，也需要认真检查、明确运行责任，并及时应对异常。

拟参赛形式：AI 图文 · 三张系列海报。AI 用于场景生成、定点编辑与辅助审查，完整提示词和修订记录随作品保存。

## 系列海报

### 01 · 一直没出事，不等于没风险。

[![供电安全海报](materials/01_供电安全.png)](materials/01_供电安全.png)

插排不串接。增加设备，先请专业人员核定供电容量。

### 02 · 只是跑一夜，也要有人负责。

[![散热与连续运行海报](materials/02_散热与连续运行.png)](materials/02_散热与连续运行.png)

不挡风口，不堆杂物。连续运行按规程落实责任、监测与异常响应。

### 03 · 闻到焦糊味，别等系统报警。

[![异常与撤离海报](materials/03_异常与撤离.png)](materials/03_异常与撤离.png)

远离、提醒，按预案撤离。不为保存数据停留，不返回取设备。发现或怀疑火情，在安全处及时拨打 119。
